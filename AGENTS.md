# SUSE Linux MCP Server

## Purpose
A MCP server that bridges AI Agents with the SUSE Linux ecosystem.
Enables safe, reliable access to trusted sources of information about SUSE Linux, SUSE Linux package repositories, and enables introspection of running SUSE Linux instances.

## Coding standards
Use latest versions of libraries and idiomatic approaches as of today.
Keep it simple. NEVER over-engineer, ALWAYS simplify, NO unnecessary defensive programming. No extra features - focus on simplicity.
Be concise. Keep README.md minimal. IMPORTANT: no emojis ever.
When hitting issues, always identify root cause before trying a fix. Do not guess. Prove with evidence, then fix the root cause.
Ensure robust and up-to-date unit tests exist, and use them whenever making code changes.
