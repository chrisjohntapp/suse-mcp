# SUSE Linux MCP Server

## Purpose
A MCP server that bridges AI Agents with the SUSE Linux ecosystem.
Enables safe, reliable access to trusted sources of information about SUSE Linux, SUSE Linux package repositories, and enables introspection of running SUSE Linux instances.
